# CruftX

一个原生 macOS 垃圾清理工具，界面遵循 Apple 人机界面指南（HIG）。由AI开发

当前版本：**1.2.1**

## 软件全部由AI开发

## 安全声明

软件可能会造成文件误删，软件作者对误删行为不负责任

## 注意

**卸载残留**误删文件概率极大，请谨慎操作

卸载残留全部默认不勾选并标注为高风险；日常清理默认只勾选低风险内容。

## 功能

- **概览面板**：可回收空间、清理进度环、风险概览、各分类进度条与快捷跳转
- **日常垃圾**：应用缓存、日志、诊断报告、Xcode 派生数据、临时文件，以及微信/企业微信/QQ/钉钉/飞书等办公软件缓存；默认只勾选低风险内容
- **双视图浏览**：日常垃圾可切换「按分类 / 按应用」，自动识别每项垃圾所属软件
- **清理风险标注**：每一项标注 低 / 中 / 高风险，默认只清理低风险内容
- **卸载残留**：检测已卸载应用遗留的应用支持文件、容器、偏好设置、缓存、窗口状态、网络存储、日志（全部默认不勾选，标注高风险）
- **残留忽略分类**：每个残留项可“暂时忽略 7 天”或“永久忽略”，列表分为“未忽略 / 暂时忽略”，已忽略项可随时取消
- **垃圾搜索**：日常垃圾、卸载残留、回收站均可按名称/路径/应用搜索；卸载应用页支持按显示名搜索
- **卸载应用**：列出已安装应用，一键将应用本体（可选相关数据）移入废纸篓
- **常用应用数据库**：内置常见应用的包名 → 显示名称映射（如 com.tencent.xinWeChat → 微信），应用名下方小字显示包名
- **中英双语**：设置 → 语言 可切换“跟随系统 / 中文 / English”，整个界面即时生效
- **清理去向**：设置 → 清理去向 可选“系统废纸篓”或“CruftX 回收站”；回收站支持逐项还原、永久删除和一键清空
- **自动更新**：启动时自动检查 GitHub Releases 新版本（每天一次），也可手动检查并下载安装镜像
- **安全清理**：每一项可先在 Finder 中查看；所有清理都可恢复（废纸篓或 CruftX 回收站）

## 构建

需要 macOS 13+ 和 Command Line Tools（含 Swift 6）。

```sh
./build.sh
```

产物：

- `build/CruftX.app` — 可双击运行的应用
- `build/CruftX.zip` — 可分发的压缩包

## 制作发布 DMG

```sh
./build.sh        # 先构建应用
./make_dmg.sh     # 生成带背景和 Applications 快捷方式的安装镜像
```

产物：`build/CruftX-1.2.1.dmg`。版本号从 `Resources/Info.plist` 自动读取，升级时只需修改版本号后重新打包。首次运行 `make_dmg.sh` 会在 `build/dmg-venv` 中安装 dmgbuild（需联网）。

## 发布与自动更新

1. 在 GitHub Releases 创建新 Release，tag 填 `v1.2.1`
2. 上传 `build/CruftX-1.2.1.dmg` 作为附件
3. 应用启动时会检查该仓库最新 Release，发现更高版本即可下载更新

发布到 GitHub Releases 后，用户下载的 DMG 会被标记为“从互联网下载”，首次打开应用时若提示无法验证开发者，可在「系统设置 → 隐私与安全性」中点击「仍要打开」。

## 说明

- 扫描范围是当前用户目录（`~/Library/...`），无需 root 权限
- 卸载残留采用启发式匹配（文件夹/包 ID 与已安装应用比对），建议清理前确认勾选项
- 首次运行时若 macOS 提示未签名应用，可在「系统设置 → 隐私与安全性」中允许打开
