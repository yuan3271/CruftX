# CruftX

一个原生 macOS 垃圾清理工具，界面遵循 Apple 人机界面指南（HIG）。由AI开发

## 注意

**卸载残留**误删文件概率极大，请谨慎操作

## 功能

- **概览面板**：可回收空间、清理进度环、一键扫描/清理
- **日常垃圾**：应用缓存、日志、诊断报告、Xcode 派生数据、临时文件，默认只勾选安全项
- **卸载残留**：检测已卸载应用遗留的应用支持文件、偏好设置、缓存、窗口状态、网络存储、日志（默认不勾选）
- **办公专清**：微信图片/视频/文件缓存、网页缓存与下载临时文件；聊天记录数据库（db_storage）永不扫描
- **卸载应用**：列出已安装应用，一键将应用本体（可选相关数据）移入废纸篓
- **常用应用数据库**：内置常见应用的包名 → 显示名称映射（如 com.tencent.xinWeChat → 微信），应用名下方小字显示包名
- **安全清理**：每一项可先在 Finder 中查看；所有清理都先移入废纸篓，可随时恢复

## 构建

需要 macOS 13+ 和 Command Line Tools（含 Swift 6）。

```sh
./build.sh
```

产物：

- `build/CruftX.app` — 可双击运行的应用
- `build/CruftX.zip` — 可分发的压缩包

## 制作发布 DMG

```sh
./build.sh        # 先构建应用
./make_dmg.sh     # 生成带背景和 Applications 快捷方式的安装镜像
```

产物：`build/CruftX-1.0.dmg`。首次运行 `make_dmg.sh` 会在 `build/dmg-venv` 中安装 dmgbuild（需联网）。

发布到 GitHub Releases 后，用户下载的 DMG 会被标记为“从互联网下载”，首次打开应用时若提示无法验证开发者，可在「系统设置 → 隐私与安全性」中点击「仍要打开」。

## 说明

- 扫描范围是当前用户目录（`~/Library/...`），无需 root 权限
- 卸载残留采用启发式匹配（文件夹/包 ID 与已安装应用比对），建议清理前确认勾选项
- 首次运行时若 macOS 提示未签名应用，可在「系统设置 → 隐私与安全性」中允许打开
